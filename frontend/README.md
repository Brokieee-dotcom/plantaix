# PLANT-X Botanical Research Frontend

Futuristic AI-powered botanical research platform built with React 19, TypeScript, Vite, and Tailwind CSS.

## Features

- **Zero-Blank-Screen Assurance**: Includes trailing-slash normalization guard, inline HTML botanical loader, 404 SPA handler, and React ErrorBoundary.
- **Specimen Registry**: Multi-cohort botanical profiles (*Arabidopsis*, *Solanum*, *Monstera*, *Ocimum*) with real curated high-resolution photography.
- **Interactive AI Vision Scanner**: Multi-stage optical leaf diagnostics with laser HUD animation and structured botanical dossiers.
- **Microclimate Telemetry**: Substrate moisture %, chamber temperature, humidity, and continuous Tetens Vapor Pressure Deficit (VPD in kPa).
- **Dr. Xylem AI Consultation**: Botanical research chatbot powered by Gemini 3.8 Flash Vision.
- **Morphological Image Lab**: Side-by-side split comparison for pre-wilting leaf angle and margin changes.
- **CCTV Enclosure Grid**: 4-channel growth enclosure monitoring with live HUD telemetry overlays.
- **GitHub Pages Ready**: Out-of-the-box support for static branch deployments with relative asset paths.

## Local Development

```bash
npm install
npm run dev
```

## Build for GitHub Pages

```bash
npm run build
```
Outputs to `dist/`, ready to deploy to any GitHub Pages repository or branch.
